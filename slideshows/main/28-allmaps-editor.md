The **Editor** is where maps are georeferenced: the four steps you saw earlier. This is Yale's organization page in it, listing every Yale map that Allmaps knows about. Pick any one and start placing points; there is nothing to install and no account to create.

[editor.allmaps.org/organizations/yale](https://editor.allmaps.org/organizations/yale)

We have also been talking with Julia Hernández at the Beinecke about how to use Allmaps in classroom teaching with these collections.
